Disposable Only

Cache Cleanup

Removes only files inside Northbound’s reserved, reproducible cache category. Uploaded avatars, source media, unknown files, Stored Backups, rollback data, and staged restores are never eligible.

Persistent History

Audit History Pruning

Permanently deletes audit events older than the selected retention age. Accounts, groups, and newer audit history are not deleted.

Deleted history is recoverable only from an appropriate backup. Approximate per-event disk usage is not shown because audit records share database pages and a separate estimate would be misleading.
