Installation Checklist

  1. Northbound does not ship a shared hosted OAuth application. Create your own Hardcover Developer App using the values above.
  2. Save its Client ID and one-time Client Secret, then enable OAuth. Blank Client Secret keeps the saved encrypted value.
  3. Readers connect from My Account and choose their own consent settings; both start OFF.

Keep NORTHBOUND_TOKEN_ENCRYPTION_KEY unchanged and backed up separately from your database. Existing installations without that setting use a key derived from DJANGO_SECRET_KEY; keep that original secret instead. Changing the active key makes saved credentials unreadable.

After a restore, Readers must reconnect OAuth. If your public origin changes, update the Developer App's Website URL and exact Redirect URI, then save this configuration again. A different Developer App requires Reader reconnect. Disabling this configuration stops Reader OAuth use, but does not disable personal API keys or Group catalog connections.

Configuration status checks local settings and decryption only; it does not prove provider availability. See the official OAuth discovery document for provider endpoints.
